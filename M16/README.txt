M16 – Website Projects
======================

This ZIP contains the lesson activity and ACP pages plus supporting pages for the multi-page sample website.

Lesson mapping:
L1 = Lesson 91 Navigation Bar
L2 = Lesson 92 Slider in Website
L3 = Lesson 93 Content Display
L4 = Lesson 94 Footer in Website
L5 = Lesson 95 Website Part 1
L6 = Lesson 96 Website Part 2 / Contact Us

Files:
L1ACT1.html, L1ACP.html
L2ACT1.html, L2ACP.html
L3ACT1.html, L3ACP.html
L4ACT1.html, L4ACP.html
L5ACT1.html, L5ACP.html
L6ACT1.html, L6ACP.html
index.html, about.html, projects.html, contact.html

These are original practice implementations based on the activity titles, not exact copies of the supplied Replit projects. The contact form validates in the browser but does not send messages to a server.
For the multi-page site, keep all files in the same folder so the navigation links work.

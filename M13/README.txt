M13 – JavaScript Activities
===========================

This ZIP contains standalone HTML practice pages based on the M13 activity titles.
Naming follows the previous M12 bundle convention:
- L1 = Lesson 73
- L2 = Lesson 74
- L3 = Lesson 75
- L4 = Lesson 76
- L5 = Lesson 77
- L6 = Lesson 78
- ACT1, ACT2, etc. = activity number
- ACP = activity completion project

Open any .html file in a browser. JavaScript examples are included in each page.
These are original practice implementations based on the titles supplied, not exact copies of the original Replit projects.

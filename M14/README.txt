M14 – JavaScript Activities
===========================

Standalone HTML practice implementations based on the activity titles supplied.

Naming:
L1 = Lesson 79, L2 = Lesson 80, L3 = Lesson 81, L4 = Lesson 82,
L5 = Lesson 83, L6 = Lesson 84.
ACT1, ACT2, etc. correspond to activity numbers. ACP is the activity completion project.

Open the HTML files directly in a browser. These are original examples, not exact copies of the original Replit projects.
The "Validation Using API" page uses a simulated local API and does not contact an external server.
